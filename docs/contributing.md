# Contributing

Awesome that you are reading this!

The goal of this repository is to help do peer observation of teaching.
Suggestions are welcomed that help achieve this goal,
with a preference to accept suggestions.

- For questions, you can
  [create an issue](https://github.com/SciLifeLab/peer_observation_of_teaching_group/issues)
  or [contact us](contact_us.md)
- For textual changes, you can use a [pull request](https://en.wikipedia.org/wiki/Distributed_version_control#Pull_requests),
  [create an issue](https://github.com/SciLifeLab/peer_observation_of_teaching_group/issues)
  or [contact us](contact_us.md)

This GitHub follows the
[Contributor Covenant Code of Conduct](code_of_conduct.md).
